Fix dropdown selected value not displaying: revert WrappingMenuItem

WrappingMenuItem used Box/Typography as MenuItem children, which
broke MUI's TextField select rendering of the selected value (the
name wasn't appearing after selection).

Reverted to plain MenuItem with text children. The global theme
override (MuiMenuItem: whiteSpace normal, wordBreak break-word)
already handles text wrapping on mobile — no need for a custom
component.

Removed WrappingMenuItem.tsx (no longer used).
