Gate pass: allow creation from approved PO without invoice

Previously a gate pass could only be created after an invoice was
generated and verified. Now it can be created as soon as the PO is
approved — invoice is optional.

Changes:
- Prisma: GatePass.invoiceId is now nullable (migration applied)
- Shared schema: invoiceId is optional in createGatePassSchema
- Backend /approved-pos: returns ALL approved POs, not just those
  with verified invoices
- Backend POST /: invoice validation is conditional — only validates
  if invoiceId is provided. Duplicate check adapts: checks by invoiceId
  when present, by poId when no invoice
- Backend verify-otp: only updates invoice stock status if an invoice
  is linked to the gate pass
- Frontend: invoice select is optional (only shown if PO has invoices),
  includes a "— None —" option. Create button no longer requires
  invoice selection. Helper text updated
