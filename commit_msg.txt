Installment payments + outstanding balance tracking + mobile approval cards

Payment system now supports multiple installments per invoice with
automatic outstanding balance calculation.

Backend (payment.routes.ts):
- getInvoicePaymentSummary(): calculates paidToDate (advance + all
  PAID installments) and outstanding (total - paidToDate)
- recalcInvoicePaymentStatus(): auto-sets PAID/PARTIALLY_PAID/PENDING
  based on outstanding after each payment
- GET /pending-invoices: returns installmentsPaid, paidToDate,
  outstanding; only blocks invoices with active PENDING/APPROVED
  requests (PAID/REJECTED no longer block new installments)
- POST /invoice-payment: validates against outstanding (not total);
  rejects zero/negative amounts
- POST /:id/pay: calls recalcInvoicePaymentStatus() instead of
  blindly setting PAID

Backend (invoice.routes.ts):
- Invoice creation: sets PARTIALLY_PAID if advance > 0
- GET /:id/payments (new): returns full payment ledger with
  advance + installment entries and summary

Shared (enums.ts):
- Added PARTIALLY_PAID to PaymentStatus enum
